# Unofficial Hollow Knight RPG — Foundry VTT System

Минимальная система для Foundry VTT 13 под русскую адаптацию The Unofficial Hollow Knight RPG.

## Текущее состояние

Ветка `feature/mvp-item-sheets` расширяет MVP до рабочего каркаса листов:

- Actor type: `bug`.
- Item types: `weapon`, `armor`, `condition`, `trait`, `path`, `art`, `spell`, `charm`, `consumable`, `gear`.
- Лист жука: характеристики, запасы, вторичные параметры, умения, группы предметов и кнопки создания встроенных Item.
- Броски: d6-пул, успех на 5–6, один переброс за `.5` характеристики.
- Атака: выбранная цель, дистанция, штраф дальности, налог и вложение Выносливости, ПУ брони, Впитывание Панцирем, Поглощение, списание Сердец.
- Состояния: базовые модификаторы к кубам атаки, кубам защиты и скорости.

## Установка для теста

Скопируйте репозиторий в директорию систем Foundry:

```bash
git clone https://github.com/sergey-kznetsov/hk-rpg-foundry.git hk-rpg
cd hk-rpg
git checkout feature/mvp-item-sheets
```

Путь должен получиться примерно таким:

```text
FoundryVTT/Data/systems/hk-rpg/system.json
```

После перезапуска Foundry создайте мир на системе `Unofficial Hollow Knight RPG`.

## Что тестировать в первую очередь

1. Создание Actor типа `bug`.
2. Изменение характеристик, запасов, размера, скорости, голода, Жути, Привлекательности и Меток.
3. Создание встроенных Item с листа жука.
4. Открытие и редактирование каждого типа Item.
5. Перетаскивание `weapon` и `armor` на лист жука.
6. Атака по выбранной цели на сцене.
7. Снижение Сердец цели, учёт ПУ, Впитывания и прочности брони.
8. Состояния с `attackDiceDelta`, `defenseDiceDelta`, `speedDelta`.

## Следующие крупные задачи

- Разделить Actor на `character`, `npc`, `creature`, если потребуется разная логика листов.
- Добавить импорт готовых черт, оружия, брони, амулетов, путей, искусств и тайн из компедиумов.
- Реализовать полноценные карточки атаки/защиты в чате вместо простого текстового отчёта.
- Реализовать подготовленные Искусства и Тайны с затратой Выносливости/Души.
- Добавить отдых, восстановление Выносливости, Души, Сердец, Сытости и обработку Голода.
- Добавить миграции данных при изменении `template.json`.
