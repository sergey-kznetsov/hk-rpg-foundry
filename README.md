# Unofficial Hollow Knight RPG — Foundry VTT System

Система для Foundry VTT 13 под русскую адаптацию The Unofficial Hollow Knight RPG.

## Текущее состояние

`main` содержит рабочий каркас листов, базовых механик и контентного слоя:

- Actor type: `bug`.
- Item types: `weapon`, `shield`, `armor`, `focus`, `condition`, `trait`, `path`, `art`, `spell`, `charm`, `consumable`, `gear`.
- Лист жука: характеристики, запасы, вторичные параметры, умения, группы предметов и кнопки создания встроенных Item.
- Калькулятор персонажа на листе жука: шаблон размера, лимит черт, Голод, Метки, вес/перегруз, подготовленные техники, расход Сытости и предупреждения по сборке.
- Броски: d6-пул, успех на 5–6, один переброс за `.5` характеристики.
- Атака: выбранная цель, дистанция, штраф дальности, налог и вложение Выносливости, ПУ брони, Впитывание Панцирем, Поглощение, списание Сердец.
- Состояния: базовые модификаторы к кубам атаки, кубам защиты и скорости.
- Базовые макро-механики: восстановление Выносливости, Фокусировка Души, Отдых.
- Контентные seed-файлы: предметы, правила, монстры/существа и НИПы.
- Импортёр создаёт вложенные папки для предметов, НИПов и монстров/существ.

## Установка для теста

Скопируйте репозиторий в директорию систем Foundry:

```bash
git clone https://github.com/sergey-kznetsov/hk-rpg-foundry.git hk-rpg
```

Путь должен получиться примерно таким:

```text
FoundryVTT/Data/systems/hk-rpg/system.json
```

Также можно установить через Manifest URL:

```text
https://raw.githubusercontent.com/sergey-kznetsov/hk-rpg-foundry/main/system.json
```

После перезапуска Foundry создайте мир на системе `Unofficial Hollow Knight RPG`.

## Импорт контента

Откройте мир под пользователем-Мастером и выполните в консоли браузера или в макросе Foundry:

```js
await game.hk.importContent();
```

Доступны отдельные команды:

```js
await game.hk.importItems();
await game.hk.importCreatures();
await game.hk.importNpcs();
```

Для повторной раскладки уже импортированного контента по актуальной структуре папок:

```js
await game.hk.organizeContent();
```

Импортёр не дублирует документы, уже созданные из того же seed-источника. При повторном запуске он перемещает старые импортированные документы в актуальные папки.

## Калькулятор персонажа

На листе жука есть блок `Калькулятор персонажа`. Он считает:

- лимит основных черт `7`, подчёрты отдельно;
- максимум Голода по шаблону размера;
- занятые и свободные Метки амулетов;
- подготовленные Искусства и Тайны против Ячеек техник;
- Нагрузку, удвоенную Нагрузку и перегруз;
- максимальную Сытость и расход Сытости за отдых;
- предупреждения по превышениям.

Кнопка `Применить шаблон` выставляет базовые параметры Мелкого, Среднего или Большого жука. Кнопка `Синхронизировать максимумы` подтягивает эффективные максимумы запасов в базовые поля листа и обрезает текущие значения, если они выше максимума.

Служебные команды:

```js
await game.hk.applySizeTemplate(actor, "small");
await game.hk.applySizeTemplate(actor, "medium");
await game.hk.applySizeTemplate(actor, "large");
await game.hk.syncActorMaximums(actor);
```

## Служебные макросы

```js
await game.hk.recoverStamina(actor);
await game.hk.focusSoul(actor, { soulCost: 1, heal: 1 });
await game.hk.rest(actor, { long: false });
await game.hk.rest(actor, { long: true });
```

## Что тестировать в первую очередь

1. Создание Actor типа `bug`.
2. Применение шаблонов размера на листе жука.
3. Изменение характеристик, запасов, размера, скорости, голода, Жути, Привлекательности и Меток.
4. Создание встроенных Item с листа жука.
5. Открытие и редактирование каждого типа Item, включая `shield` и `focus`.
6. Импорт контента через `await game.hk.importContent()`.
7. Повторная организация контента через `await game.hk.organizeContent()`.
8. Перетаскивание `weapon`, `shield`, `armor`, `focus`, черт, Путей, амулетов и расходников на лист жука.
9. Проверка предупреждений калькулятора: больше 7 черт, слишком много Меток, перегруз, слишком много подготовленных техник.
10. Атака по выбранной цели на сцене.
11. Снижение Сердец цели, учёт ПУ, Впитывания и прочности брони.
12. Состояния с `attackDiceDelta`, `defenseDiceDelta`, `speedDelta`.
13. Макросы восстановления Выносливости, Фокусировки и Отдыха.
